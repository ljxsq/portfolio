## 项目背景

面向面试练习的个人项目：输入简历与岗位描述后生成针对性题目，在浏览器逐题录制视频作答，全部完成后统一评估并生成报告。核心流程覆盖出题、答题、报告三个阶段。

## 核心实现方案

### 1. Coze 工作流承担出题、评估与图片 OCR

出题、回答评估和 JD 截图识别分别调用 Coze 工作流。服务端统一封装 `runWorkflow`，仅在 HTTP 429 且确认限流时按 `Retry-After` 或 1s、2s 指数退避重试。这样无需自建模型服务，也能把模型调用细节收敛在一处，并在限流时自动恢复。

### 2. 录制与评估解耦

浏览器使用 `MediaRecorder` 录制，优先 MP4（H.264 + AAC），不支持时回退 WebM。每题录完只上传视频并标记为「已录制待评估」，最后一题再逐题调用评估接口。这样避免每题阻塞等待模型结果，也支持单题失败重试，以及重录后覆盖旧记录。

### 3. 单文件 JSON 的原子持久化

用户、会话、题目、答案与待评估记录写入 `data/interview.json`。写入先落临时文件再 `rename`，并用挂在 `globalThis` 上的 Promise 队列串行化所有读写。这样在没有数据库的单机部署下避免并发写入互相覆盖，同时保持部署简单。

### 4. JWT 登录与资源归属校验

登录签发 HS256 JWT 并写入 HttpOnly Cookie，API 层统一校验登录态，会话与题目再校验归属，越权统一返回 404。这样不引入第三方认证服务，也避免通过响应泄露资源是否存在。

## 功能与亮点

- **出题**：支持粘贴或上传简历 / JD 文本；简历支持 PDF、DOCX、TXT、MD，JD 支持 PNG、JPG、JPEG、WEBP 截图；由 Coze 工作流生成题干、评分要点与难度。
- **答题**：逐题视频录制、回看与重录；录完只上传，不立即评估，最后一题统一提交。
- **报告**：总分，以及表达清晰度、技术深度、岗位相关性三维均分；每题展示已覆盖要点、遗漏要点与评语，兜底评分题单独标记。
- **部署**：Next.js 生产构建后通过 `npm start` 启动；需要配置 Coze 访问令牌、出题与评估工作流 ID，以及 JWT 签名密钥，数据保存在本地磁盘。

## 补充说明

- 存储为单机文件方案，不支持多实例或横向扩展；视频文件没有 TTL 或清理任务。
- 项目没有自动化测试与 CI；登出只清除 Cookie，不能服务端吊销已签发 JWT。
- 这是个人项目，已提供线上预览地址；仓库源码与可核实的量化运营数据暂未公开，因此未填写 `repoUrl`、`results` 和细节截图。
